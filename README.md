# Daf Yomi · הדף היומי

Daily Talmud learning in English and Hebrew. Find the daily daf, open its two sides, browse all forty tractate entries, and read the available study guides with their sources.

The reader uses Jerusalem time and follows the worldwide Daf Yomi cycle. Choose English, Hebrew or a parallel reading. Sefaria and Sanhedrin provide connected source libraries. Rabbi portraits accompany the learning; text authors and original sources retain their own attribution.

The daily Pages build updates the calendar without any model API. Calendar calculation follows Hebcal's public-domain modern-cycle algorithm; see `reader/data/tractates.json`. Hebcal API verification is attributed under CC BY 4.0. Portrait provenance and checksums are recorded in `reader/rabbis.json`.
